Two problems with that pattern. Every image loaded eagerly, so a write-up with 26 of them (image-inpainting) competed with the text for bandwidth on first paint. And `width="90%"` is a demand, not a ceiling: an image whose source was narrower than 90% of the column was stretched up to it and blurred. Here the same number becomes a max-width, so a figure fills the column when it can and is never enlarged past its own resolution. Usage — single panel: {% include figure.html image_path="/images/foo/plot.png" alt="Training loss" caption="Figure 3. Training loss." width="90" %} Two panels side by side (the caption should name left and right itself): {% include figure.html image_path="/images/foo/before.png" image_path_2="/images/foo/after.png" alt="Before" alt_2="After" caption="Before (left) and after (right)." %} Three panels, for a set of comparable items — three difficulty settings, three layouts. Falls back to the two-column grid below the small breakpoint: {% include figure.html image_path="/images/foo/easy.png" image_path_2="/images/foo/medium.png" image_path_3="/images/foo/hard.png" caption="Easy, medium and hard (left to right)." %} Arguments: image_path required. Root-relative, as the markdown already writes it. image_path_2 optional. Presence switches the figure to the two-panel layout. image_path_3 optional. Presence switches it to the three-panel layout, and takes precedence over image_path_2. alt / alt_2 / alt_3 description of what the image shows. caption optional; omit and no figcaption is emitted. width percent of the column, used as a ceiling. max_px pixel ceiling, for images whose native width is known to be narrower than the column. Takes precedence over width. dims "WxH", the image's intrinsic size, emitted as width/height attributes. CSS keeps them from setting the rendered size (height stays auto), but the browser uses them to reserve the right box before a lazy image arrives — without this, a page with 26 figures reflows its way down the scroll. dims_2 same, for the second panel. dims_3 same, for the third panel.
